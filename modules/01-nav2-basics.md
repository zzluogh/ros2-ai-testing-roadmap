## 核心架构

```
传感器数据 → 定位(AMCL) → 全局规划器 → 局部控制器 → 机器人底盘
                ↓              ↓              ↓
            全局代价地图    全局路径       局部代价地图 + 速度指令
```

### 五大核心组件

| 组件 | 核心任务 | 输入 | 输出 |
|------|---------|------|------|
| **Planner（规划器）** | 全局路径规划 | 地图 + 起点 + 终点 | 全局路径（waypoints） |
| **Controller（控制器）** | 局部轨迹跟踪 | 全局路径 + 局部代价地图 | `/cmd_vel` 速度指令 |
| **BT（行为树）** | 编排导航任务 | 导航目标 | 调度各服务器的执行顺序 |
| **AMCL** | 自适应蒙特卡洛定位 | 激光扫描 + 里程计 | 机器人位姿估计 |
| **Costmap** | 代价地图 | 传感器数据 + 静态地图 | 二维栅格代价图（0~254） |

### 代价地图层级

```
          ┌──────────────────────┐
          │     Master Layer     │ ← 主层（总是第一层）
          └──────────┬───────────┘
     ┌───────────────┼───────────────┐
     │               │               │
┌────▼────┐   ┌──────▼──────┐  ┌─────▼─────┐
│ Static   │   │  Obstacle   │  │ Inflation │
│  Layer   │   │   Layer     │  │   Layer   │
│ (静态地图)│   │  (激光雷达)  │  │  (膨胀层)  │
└─────────┘   └─────────────┘  └───────────┘
```

### 关键参数速查

| 参数 | 含义 | 典型值 |
|------|------|--------|
| `robot_radius` | 机器人半径 | 0.22 m |
| `inflation_radius` | 膨胀半径 | 0.55 m |
| `cost_scaling_factor` | 代价缩放因子 | 3.0 |
| `resolution` | 地图分辨率 | 0.05 m/格 |
| `rolling_window` | 局部代价地图是否跟随机器人 | True |
| `min_particles` | AMCL 最少粒子数 | 500 |
| `max_particles` | AMCL 最多粒子数 | 2000 |
| `update_min_d` | 最小平移更新距离 | 0.25 m |
| `update_min_a` | 最小旋转更新角度 | 0.2 rad |

### 行为树结构（默认）

```
PipelineSequence (恢复行为)
├── RecoveryNode (可选恢复步骤)
│   ├── Spin (原地旋转)
│   ├── Backup (后退)
│   └── Wait
└── 导航主流程
    ├── ComputePathToPose (计算全局路径)
    ├── FollowPath (执行局部路径)
    └── ...
```
