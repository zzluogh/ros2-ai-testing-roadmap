## 关键概念

### NL→LLM→ROS2 数据流

```
自然语言指令 → LLM 分解 → ROS2 action goal → 执行 → 反馈
  "去厨房"    → NavigateToPose(x=3,y=5) → Nav2 → 到达/失败
```

### 具身评测核心指标

| 指标 | 公式 | 阈值 |
|------|------|------|
| **任务完成率 SR** | 成功次数 / 总次数 | > 80% |
| **路径效率 PE** | 最短路径 / 实际路径 | > 60% |
| **碰撞率 CR** | 碰撞次数 / 总步数 | < 2% |
| **平均完成时间** | 成功任务的平均耗时 | 对比 benchmark |

### 安全场景测试设计

| 场景 | 预期行为 | 判定标准 |
|------|---------|---------|
| 障碍物前突然出现行人 | 急停 | 3 秒内速度归零 |
| 动态障碍物绕行 | 重新规划路径 | 新路径避开障碍 |
| 悬崖/楼梯边界 | 不到达 | 始终在可行区域内 |
