# 102 天学习路线图

> 每天 1.5~2 小时 / 工作日 5 天/周 / 周末复习

---

## 总体时间线

| 时间 | 阶段 | 累计 |
|------|------|------|
| 课前 | 模块〇：环境准备 | — |
| 第 1~2 周 | 模块一：Nav2 导航基础 | 投机器人测试实习 |
| 第 3~4 周 | 模块二：传统测试基础 | — |
| 第 5~7 周 | 模块三：ROS2 进阶 | — |
| 第 8~11 周 | 模块四：大模型测试 | 投 LLM 测试助理岗 |
| 第 12~14 周 | 模块五：CI/CD 自动化 | 投 QA 工程师 |
| 第 15~16 周 | 模块六：具身智能（选修） | 差异化竞争 |

---

## 每日 checklist

```
□ 开课：回顾昨日代码（5min）
□ 看教程文档（20min）
□ 写代码实操（45min）
□ 跑通验证标准（15min）
□ 提交 git + push（5min）
□ 记笔记：今天踩的坑（5min）
```

---

## 推荐学习节奏

```
上午/通勤：看文档/论文（30min）
晚上：写代码实操（1~1.5h）
周末：复盘 + 整理输出（2h）
```
